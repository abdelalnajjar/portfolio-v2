Responsive portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Current content

- Software Engineer positioning with AI/ML, Cloud Computing, and Backend Systems focus
- Cloud-Native Order API deployed across AWS services
- Expenses Management System
- Privacy-Preserving Fall Detection research
- Education, graduate coursework, experience, resume, LinkedIn, GitHub, and contact information

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the files and the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and choose `/ (root)`.
5. Save. GitHub will provide the public website URL.

The QR code should be generated after the final GitHub Pages URL is selected.
